# 违规词检测

一个纯前端的违规词检测工具，粘贴文案即可自动高亮违规词，支持自定义词库、启用/禁用、导入导出，数据不离开浏览器。

## 功能

- **自动检测高亮**：粘贴文案，实时高亮命中的违规词，按长度倒序匹配避免短词误伤
- **内置词库**：涵盖极限绝对化、医疗功效、诱导消费、金融投资、传销分销、低俗色情、赌博博彩、诈骗欺诈、政治敏感等十大分类
- **自定义词库**：添加、搜索、删除自定义词，一键启用/禁用
- **导入 / 导出**：词表以 JSON 格式导入导出，方便备份和分享
- **命中统计**：实时统计命中次数最多的词
- **数据隐私**：所有检测和存储均在浏览器本地完成，不联网、不上传

## 使用方法

直接用浏览器打开 `index.html` 即可使用，无需安装任何依赖。

## 操作说明

| 操作 | 说明 |
|------|------|
| 粘贴文案 | 在左侧输入框粘贴文本，右侧自动高亮违规词 |
| 添加词 | 在"添加词"输入框输入，支持逗号/空格分隔多个，回车或点击添加 |
| 启用/禁用 | 点击词标签切换，划线表示已禁用 |
| 删除词 | 点击标签上的 ✕ 删除自定义词 |
| 导入/导出 | 点击按钮导入或导出词表 JSON 文件 |
